# Reward Cards — Collectible System

Every time you complete a task card, you pull a **reward card** — a randomized collectible with its
own art and a bit of flavor text. Think trading cards, but for actually getting things done.

## How It Works

1. Complete a task card (do the work, comment "Done ✅")
2. Pull a reward card — picked at random from the current set (see below)
3. It gets added to your personal collection (tracked in `docs/collections/<your-name>.md`)
4. Rarer cards show up less often — collecting the full set is its own long-term goal

## Rarity Tiers

| Tier | Odds | Feel |
|---|---|---|
| ⚪ Common | 60% | "nice, got one" |
| 🟢 Uncommon | 25% | "oh cool" |
| 🔵 Rare | 12% | "no way!" |
| 🟡 Legendary | 3% | screenshot it and post it |

## Adding New Cards

As the board grows, add new cards here for new categories of work (partnerships, marketing, etc.)
so nobody runs out of surprises. Keep the tone light — these should feel like a treat, not a KPI.

## Collections

Each person's pulled cards are tracked in `docs/collections/<name>.md` — created automatically the
first time someone completes a card (or manually, whichever is faster for now).
