**Goal:** Bundle 3-5 of the existing written guides/docs in the ecosystem into a new sellable ebook.

**Time:** 45-60 minutes

**Reward:** Gold star + a brand new product with zero new writing.

## Background

There are a huge number of guides, checklists, and playbooks already written across these repos that nobody has packaged as a product. This card is about finding and combining a few into one polished ebook.

## Steps

1. Look through these repos for finished, polished docs (skip drafts/WIP):
   - `AgentCorps/` — agent orchestration doctrine and playbooks
   - `OmniTender/docs/sales/` — sales playbooks, vertical kits
   - `neural-network/handoffs/` — session wraps with real learnings
   - Any game design docs in `MeniscusMaximus` (read-only, ask before touching)
2. Pick a theme that ties 3-5 docs together (e.g., "How to Run a Multi-Agent Dev Team" or "The Small Business Payment Processing Playbook")
3. Copy the content into one Google Doc, in a sensible order
4. Add a short intro paragraph explaining what the reader will get
5. Clean up any internal references (repo names, internal links) that won't make sense to an outside reader
6. Hand off to the Publishing Playbook (card: publish new ebook) to format and upload

## When You're Done

Comment "Done ✅" with a link to the Google Doc. Close this card.
