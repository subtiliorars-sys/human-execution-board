# Human Execution Board

**Where humans do the work that makes money.**

Every card here is:
- ✅ **Step-by-step instructions** (explain it to a 3rd grader, and they could do it)
- ✅ **A defined goal** (you know when you're done)
- ✅ **Low friction** (we've pre-thought the hard parts)
- ✅ **A reward** (gold star + celebrate on completion)

This is **not** for agents. Agents do research, design, and code. **This board is for humans** — calls, emails, approvals, publishing, marketing, decisions that need a real person's judgment.

---

## How to Use This Board

### 1. Pick a card from `Todo`
Go to the [GitHub Projects board](https://github.com/users/subtiliorars-sys/projects/2) and click a card that interests you. All cards have:
- **Goal:** What "done" looks like
- **Steps:** 1, 2, 3... (super detailed)
- **Time:** How long it takes
- **Notes:** Gotchas or links you'll need

### 2. Comment "I'll do this 👋" to claim it
Move it to `In Progress`. That's it — you own it now.

### 3. Follow the steps
If something doesn't make sense, ask in the comments. But the steps should be so clear you don't have to.

### 4. Mark it done
Comment "Done ✅" or close the issue. You get:
- A **gold star** ⭐ in the card
- A **celebration message** (we'll post it somewhere you'll see)
- A **random reward card** — a little collectible with its own art, pulled at random. See [docs/reward-cards.md](docs/reward-cards.md) for the full set and rarity tiers. Collect them all.
- Proof you made progress (the board moves)

### 5. Tell us what took longer than expected
If a card said "15 min" and took 45, just say so. We'll fix the next one.

## Rules

1. **One person per card.** Comment to claim it; don't assign yourself to two at once.
2. **If you get stuck, ask.** Comment with what doesn't make sense. We'll un-block you or clarify the step.
3. **If the card is wrong, tell us.** It says "15 min" but took an hour? Leave a comment. We'll fix it for the next person.
4. **Hand off cleanly.** Before you close it, make sure the work is actually done — don't pass a half-finished task.
